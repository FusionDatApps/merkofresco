# MerKofresco

Full-stack e-commerce platform for fresh products.

## Stack

- Frontend: Next.js
- Backend: Node.js + Express
- Database: PostgreSQL
- ORM: Prisma

## Features (current)

- Product catalog (categories & products)
- Relational database design
- Seed data for development
- REST API endpoints:
  - GET /api/categories
  - GET /api/products
